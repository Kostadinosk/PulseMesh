Official iPhone & Mobile Web

iPhone PWA, 2-Tier Root CA SSL & Mobile Features

Install PulseMesh on any iPhone or iPad via Safari (Share → Add to Home Screen) at /web/ with pinch-to-zoom tactical maps, live mobile orientation compass, voice notes, ICE medical cards, Dead-Man timer, and 1-tap Root CA installer (.mobileconfig / .crt) or zero-warning HTTP :8080 native mobile voice calling.

0xCAFE / 0xCAFF

Sub-Second BLE Discovery & GATT Mesh

Broadcasts ultra-compact 12/14-byte manufacturer beacons with 1e-7 micro-degree GPS precision and callsign scan responses. Uses deterministic GATT server/client role staggering and 160-byte serialized chunking to prevent connection collisions across Android OEM stacks.

PMU2 / PMB1

Free & Encrypted @username Accounts + Duress Wipe

Claim a cryptographic @username backed by an ECDSA P-256 keypair and PBKDF2-encrypted key vault. Supports ultrasonic tap-to-verify key fingerprints, per-message Auto-Burn TTL timers, and an emergency Duress PIN wipe.

8 kHz Full-Duplex

Voice Calls, HW Volume PTT & Radio VOX Bridge

Adaptive 8 kHz G.711 μ-law and 4-bit IMA-ADPCM voice codecs stream over local Wi-Fi/Hotspot UDP or pure BLE GATT. Hold Volume Down for screen-off PTT, or enable the 1000 Hz VOX pre-key pilot for wired VHF/UHF radios.

DTN Store & Forward

24/7 Background Relay & Flood Routing (TTL = 7)

A persistent foreground relay service holds a partial WakeLock and Wi-Fi MulticastLock so phones relay packets in a backpack, combining packet deduplication and a persistent DTN outbox that flushes automatically on peer discovery.

EPSG:3857

Download Web Mercator regional tiles and beam cached map tiles P2P to offline peers. Record GPS & step dead-reckoning breadcrumb trails with GPX import/export and shared tactical pins (RALLY, HAZARD, SUPPLY, SOS).

Quick Start

Install or Build from Source

Download the signed release APK directly to two or more physical Android phones, or build locally with Gradle:

git clone https://github.com/Kostadinosk/PulseMesh.git
cd PulseMesh
./gradlew :app:assembleDebug
Zero-Trust Crypto

End-to-End Encrypted by Default

Direct messages use ECDH P-256 key agreement with TOFU safety fingerprint verification and fresh random 96-bit IVs per packet. Channel traffic and cloud relay envelopes are sealed with PBKDF2-HMAC-SHA256 and AES-256-GCM so relay servers never see plaintext callsigns, messages, or keys.
