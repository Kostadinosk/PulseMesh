Built for Real Hardware in Degraded Environments

Every layer is engineered to survive intermittent links, OEM Bluetooth quirks, and strict off-grid isolation.

0xCAFE / 0xCAFF

Sub-Second BLE Discovery & GATT Mesh

Broadcasts ultra-compact 12/14-byte manufacturer beacons with 1e-7 micro-degree GPS precision and callsign scan responses. Uses deterministic GATT server/client role staggering and 160-byte serialized chunking to prevent connection collisions across Android OEM stacks.

PMU2 / PMB1

Free & Encrypted @username Accounts

Claim a cryptographic @username backed by an ECDSA P-256 keypair and PBKDF2-encrypted key vault. Migrate all chats, contacts, and keys to a new device using your PIN or one-time Recovery Key via gzipped PMB1: encrypted backups.

8 kHz Full-Duplex

Real-Time Voice Calls & Walkie-Talkie

Adaptive 8 kHz G.711 μ-law and 4-bit IMA-ADPCM voice codecs stream over local Wi-Fi/Hotspot UDP or pure BLE GATT, complete with half-duplex echo ducking, lock-screen call controls, a persistent mini call bar, and automatic voicemail capture.

DTN Store & Forward

Multi-Hop Flood Routing (TTL = 7)

Broadcast channels, multi-peer ECDH group chats, and direct messages automatically hop across intermediate nodes with packet deduplication, rate limiting, and a persistent Delay-Tolerant Networking (DTN) outbox that flushes when peers come into range.

EPSG:3857

Offline Tactical Map & SOS Beacons

Download Web Mercator regional tile pyramids for 100% offline navigation. Drop shared tactical pins (RALLY, HAZARD, SUPPLY, SOS), inspect peer distance and relative compass bearings, and control GPS privacy (EXACT, COARSE, OFF).

75+ Devices

Silicon Auto-Detection & Root Pro Tab

Automatically identifies Qualcomm Snapdragon, MediaTek Dimensity, Exynos, and Google Tensor radios. Includes live BLE TX/RX diagnostic panels, Pro RSSI charts, and optional root su radio power-save overrides in Dark & Daylight Frutiger Aero themes.

Quick Start

Install or Build from Source

Download the signed release APK directly to two or more physical Android phones, or build locally with Gradle:

git clone https://github.com/Kostadinosk/PulseMesh.git
cd PulseMesh
./gradlew :app:assembleDebug
Zero-Trust Crypto

End-to-End Encrypted by Default

Direct messages use ECDH P-256 key agreement with TOFU safety fingerprint verification and fresh random 96-bit IVs per packet. Channel traffic and cloud relay envelopes are sealed with PBKDF2-HMAC-SHA256 and AES-256-GCM so relay servers never see plaintext callsigns, messages, or keys.
