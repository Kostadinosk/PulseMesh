# F-Droid Fastlane Images

Place store graphics for `en-US` in this directory (`fastlane/metadata/android/en-US/images/`):

- `icon.png`: 512x512 PNG app icon (already present here).
- `phoneScreenshots/`: Drop PNG or JPEG phone screenshots here (for example `01_mesh_chat.png`, `02_tactical_map.png`, `03_ptt_voice.png`). Remove `.gitkeep` once screenshots are added.
